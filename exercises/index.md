## Workshop Exercises

The workshop includes four hands-on exercises that build on each other across the two days. The first two exercises focus on exploring and querying existing data; the second two involve running your own reconstructions.

No coding is required for any of these exercises. All work happens directly in your browser through the PReSto platform.

---

### [Exercise 1: Visualizing Existing Reconstructions](exercise-01-visualization)

Get comfortable with the PReSto interface by exploring published paleoclimate reconstructions that are already loaded and ready to view. You will navigate time periods, switch between reconstructions, and read spatial and temporal structure before building your own products.

**When:** Day 1, morning

---

### [Exercise 2: Query and Download](exercise-02-query-download)

Practice the data selection step that underlies every custom reconstruction. You will use the query interface to filter proxy records from the LiPDverse database, explore how different parameter choices affect what data gets returned, and download a set of LiPD files.

**When:** Day 1, afternoon

---

### [Exercise 3: Holocene Data Assimilation](exercise-03-holocene-da)

Run your first paleoclimate reconstructions using PReSto's Holocene data assimilation engine. This exercise focuses on how DA parameter choices and input data shape the result, using the Temp12k v1.0.2 dataset as a common starting point. Each reconstruction job takes roughly 15 minutes, so plan your runs accordingly.

**When:** Day 2, morning

---

### [Exercise 4: CFR/LMR Reconstruction with Duplicate Handling](exercise-04-cfr-lmr-deduplication)

The most involved exercise of the workshop. You will run a full reconstruction using the CFR/LMR engine from query through final product, including the deduplication step deliberately skipped in Exercise 3. The exercise is designed to reveal how much scientific judgment in deduplication affects the final reconstruction.

**When:** Day 2, afternoon
